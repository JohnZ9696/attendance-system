# Attendance System

Facial recognition and RFID attendance system organized as independent services.

## Project structure

- `backend/`: Spring Boot API and database integration.
- `frontend/`: React and Vite administration dashboard.
- `ai-service/`: FastAPI image-analysis service.
- `esp32-service/`: PlatformIO firmware for ESP32 attendance hardware.

Each service contains its own setup instructions and dependency files.
